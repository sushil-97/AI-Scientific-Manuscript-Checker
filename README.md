# AI Scientific Manuscript Quality & Discrepancy Checker

An automated scientific manuscript screening system designed to identify
potential editorial, reporting, statistical, and reproducibility issues
in scientific manuscripts.

## Current Screening Modules

- Study characteristic detection
- Ethics and consent screening
- Data availability screening
- Single/Multi-center screening
- Complementary and Alternative Medicine (CAM) screening
- Dual Use Research of Concern (DURC) screening
- Statistical consistency checking
- Sample-size consistency checking
- Reproducibility assessment
- Explainable overall editorial decision

## Technology

- Python
- NLP / rule-based text analysis
- PyMuPDF
- NLTK
- Streamlit

> This project is intended as an editorial decision-support tool. Results
> require human editorial verification and should not be interpreted as
> definitive publication decisions.
